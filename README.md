# Der diagnostische Blick XI

A child in front of the television, 1989. After Luc Tuymans, *Der diagnostische Blick* (1992).

The eyes keep closing. Press SPACE to open them again, and stay awake until the tape ends.

Play: https://blick-xi-three.vercel.app

This repository holds the web build (Godot 4.7 export) that Vercel serves. The game itself is made in Godot; this folder is regenerated by exporting the project.

Created in 2026 by AViM, based on the personal story and experiences of A. Harrosh.
